# Contributing

Thank you for the interest in Pelagium.

This repository is a public engineering showcase for a privately developed commercial product. It is **not** the open-source source tree of the application.

## Welcome contributions

Public feedback is welcome for:

- documentation corrections;
- threat-model gaps;
- security-control critique;
- architecture discussion;
- suggested AppSec test cases;
- references to relevant defensive practices.

## Not accepted here

- requests for the private source code;
- pull requests attempting to reconstruct the commercial application;
- real credentials, tokens or private user data in issues;
- reports of security vulnerabilities in public issues — use `SECURITY.md` instead.

The project owner may incorporate useful public feedback into the private product independently.
