# Security Policy

## Scope

This repository contains public engineering documentation for Pelagium. The commercial product source code and production infrastructure are private.

## Reporting a security issue

Please **do not open a public GitHub issue** for a suspected vulnerability affecting the Pelagium product or private infrastructure.

Preferred reporting channels:

1. GitHub Private Vulnerability Reporting, if enabled for this repository; or
2. a private message through the repository owner’s GitHub/LinkedIn profile until a dedicated security contact is published.

Please include:

- affected component or documented design assumption;
- steps to reproduce when applicable;
- expected vs. observed behavior;
- potential security impact;
- any suggested mitigation.

## Public issues

Public issues are appropriate for documentation errors, broken links and non-sensitive architecture discussions.

## No public production target

At the current project stage, this repository does not advertise a public production endpoint for security testing. Do not attempt to discover or attack private development infrastructure.
